## 1. Product

- **Site:** https://workutilities.com: free online tools (PDF, images, calculators, student, developer utilities). No signup.
- **Markets:** **India and USA.** Each page serves one market (India pages use ₹, lakh, Indian banks/forms; USA pages use $, 401k, W-2) or is global.
- **Sister site:** workprompts.in (AI prompt directory), linked in the footer.
- **Monetization (planned):** Google AdSense (`public/ads.txt` is already live), affiliate links on finance calculators later.

## 3. Code map

| Path | Purpose |
|---|---|
| `app/tools/<slug>/page.tsx` + `layout.tsx` | One folder per tool. `layout.tsx` holds metadata (title, description, canonical, OG) |
| `lib/tools-data.ts` | **Registry of all tools** (slug, name, description, icon, category). Adding a tool = add an entry here + a folder in `app/tools/` |
| `lib/tool-seo-content.ts` | About text, use cases and FAQs for every tool (rendered by `components/ToolSeoContent.tsx`) |
| `lib/<tool>.ts` | Pure calculation/processing logic per tool (tested in `lib/__tests__/`) |
| `app/blog/posts.ts` | Blog registry + SEO metadata. Content in `app/blog/content/<slug>.tsx`, route `app/blog/[slug]/page.tsx` |
| `app/<doc>-photo-size/` + `lib/photo-size-guides.ts` | India photo-size landing pages (Aadhaar, PAN, passport, visa, driving licence) |
| `lib/photo-resize.ts` | Photo presets (sizes/KB) + resize logic |
| `lib/currency-context.tsx` + `middleware.ts` | INR/USD handling (server HTML = INR, client switches by choice/geo) |
| `lib/seo.ts` | `buildOpenGraph()`, used by every page's metadata |
| `app/sitemap.ts`, `app/robots.ts` | Sitemap + robots. `lastmod` comes from `lib/content-dates.json` |
| `components/` | Header, Footer, MegaMenu, RelatedTools, ToolSeoContent, calculator UI, etc. |

## 4. Git workflow

- `main` = live site (Vercel auto-deploys on push). **Never push work directly to main.**
- Work happens on a branch (currently `phase-1-seo`). Every task = one commit, pushed to the branch, and gets a Vercel preview URL.
- Pavan merges to `main` at checkpoints, after testing the preview on a phone.
